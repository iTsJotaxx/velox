# Velox — product context

## Product
A fast, safe and reversible Windows 10/11 optimizer for gaming and everyday performance. A single small `.exe`
(.NET Framework 4.8, WPF) that runs elevated, scans the PC and recommends settings for that hardware.

## Users
- **The average player.** Plays a lot, doesn't know what HAGS or MPO are. Opens Velox, presses "Apply recommended"
  and wants to be sure nothing breaks.
- **The enthusiast.** Builds their own PC, watches FPS and latency, wants to see and control every setting and value.
Both weigh the same. They use Velox at their desk, often in the evening, in low light.

## What only Velox can say
- Every original value is backed up before it changes; every change can be undone, one by one or all at once.
- Every switch shows the real state of Windows; nothing changes until the user applies.
- No placebo tweaks; risky settings are labelled and never part of Recommended mode.

## Brand commitments
- Serious tool first: no neon/RGB glow, no aggressive angular shapes, no "BOOST" / "+FPS" claims, nothing that looks
  like a game HUD.
- Bold through precision, not decoration.
- Single executable: only fonts and assets that ship with Windows (Bahnschrift, Segoe UI Variable, Segoe Fluent Icons).
- English and Spanish, switchable instantly.

## Platform
Windows desktop (WPF), dark theme, custom title bar, per-monitor DPI. Minimum window 1060×680.
